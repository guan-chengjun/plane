使用说明

  • 鼠标左键拖动：360° 环绕观察；滚轮：缩放；右键拖动：平移
  • 半透明透视：机身变半透明，可观察内部结构，再次点击恢复
  • 启动引擎：螺旋桨/风扇叶片旋转、喷口发光、尾焰粒子喷出；自动按节点名称匹配引擎，匹配失败有兜底方案
  • 起落架：平滑收放动画（模型无起落架节点时按钮自动禁用）
  • 航行灯：左机翼红色、右机翼绿色、尾部白色双闪频闪
  • 姿态演示：俯仰 / 滚转 / 偏航循环动画，「一键回正」立即恢复水平姿态

如何替换飞机模型

  • 打开本文件，搜索 CONFIG 配置区，把 CONFIG.model.url 改成新的 GLB 直链即可；fallbackUrl 为备用地址
  • 模型必须是 .glb / .gltf 直链 且服务器开启 CORS（响应头含 Access-Control-Allow-Origin: *）
  • GitHub 文件可用前缀转直链：https://raw.githubusercontent.com/用户名/仓库/分支/路径.glb，或经 https://cdn.jsdelivr.net/gh/用户名/仓库@分支/路径.glb 加速
  • 若模型机头朝向不对，修改 CONFIG.model.frontAxis（可选 '+z' '-z' '+x' '-x'）
  • 引擎/起落架按名称关键字自动匹配（propeller、blade、engine、gear、wheel 等），命名规范的模型可直接获得全部特效

免费 GLB 飞机模型网站

  • Poly Pizza — poly.pizza：大量 CC 协议低模，提供 CORS 友好的 CDN 直链
  • Sketchfab — sketchfab.com：筛选「Downloadable + GLB」，下载后自行托管
  • Quaternius — quaternius.com：CC0 免费商用飞行器素材包
  • Kenney — kenney.nl：CC0 通用载具素材，含飞机
  • GitHub 开源资产库：BabylonJS/Assets、KhronosGroup/glTF-Sample-Models，raw 与 jsDelivr 链接均自带 CORS

file:// 双击跨域问题 & 本地静态服务

本页使用 ES Module + 远程模型，个别浏览器在 file:// 协议下会拦截模块或模型请求。 如双击打开后白屏或模型加载失败，请在文件所在目录启动静态服务器后访问 http://localhost:8080/aircraft-showroom.html：

  • Python（推荐，自带）：python -m http.server 8080
  • Node.js：npx serve . 或 npx http-server -p 8080
  • VS Code：安装「Live Server」插件，右键 Go Live
